# Android 0.11.0

- 全新外观：与网页工作区同一套 Claude 色板（羊皮纸底、沙色栏、陶土色主操作，无花果/橄榄/仙人掌/天空色区分标签与状态），标题和正文用衬线字体，浅色/深色都已适配。
- 阅读页：先选「原文 / 整理版」，再看「收藏原因」，然后是正文。整理状态不再显示或编辑（已有数据保留，旧版本仍能读写）。
- 分享面板：合集移到链接下方，不用下滑就能选；收藏原因随后。
- 按标签筛选：主题、资源类型、内容特征、个人标签在一个面板里，可选「全部满足 / 任一满足」，支持搜索别名；来源、时间等收在「更多条件」。
- 设置：按「连接 / 同步与上传 / 离线 / 分享 / 整理 / 应用」分组。新增「AI 打标」（每条最多建议数、建议需确认后生效、低把握仍需确认），与网页设置共用，所有设备生效。
- 标签库：整页标签详情，可改名、AI 开关、粒度、含义、正反例、别名，合并到另一个标签、查看变更记录、归档与恢复；断网时修改先存本机，联网后同步。
- AI 建议确认后生效：开启后，新判断的 AI 标签先出现在阅读页「待你确认的 AI 建议」里（虚线），点一下确认、点 × 忽略；确认前不参与筛选和合集规则。默认设置与原来的行为一致（每条最多 5 个、直接写入）。
- 合集规则：一个合集可挂多个命中标签（任一/全部），可设排除标签、只按已确认标签、审核后加入或直接加入，待审核的收藏可逐条加入或忽略。旧服务端不支持的选项会置灰并说明。

正式版本 `v0.11.0` 对应 versionCode 1100。

# Android 0.10.0

- 设置 → 分类管理 → 标签管理：新建主题、编辑名称/别名/含义/正反例、调整粒度、停用恢复和查看变更。新建标签默认参与 AI，可单独关闭。
- 合集管理 → 自动收录标签：按任一或全部最终标签收录新收藏，支持预览后补收已有收藏。手动移出会保留排除记录。
- 目录、规则和待同步修改保存到本机 SQLite，账号隔离；网络结果未知重试同一操作，明确冲突后由你核对并处理。沿用既有正文、图片缓存和正式签名。

正式版本 `v0.10.0` 对应 versionCode 1000。

# Android 0.6.0

- 收藏卡片和阅读页优先显示写真、代码重构等具体主题，最多预览 5 个标签；完整标签及人工修改保持不变。
- 主题导航保留稳定入口，支持按规范名称和别名查找全部主题、固定本机常用主题，以及基于当前结果进一步筛选。
- `topic_refinements` 与原有主题任一／全部条件独立组合，多个进一步筛选条件需全部满足。请求和响应须同时确认 `X-Cairn-Tag-System: 1` 与 `X-Cairn-Topic-Granularity: 1`；旧后端继续支持原有列表和标签，新增筛选无法确认时明确报错。
- 标签排序和导航是展示偏好，不创建个人标签，不改写收藏上的标签身份、人工选择或变更历史。固定入口按后端与账号隔离保存在本机。

正式版本号由发布 tag 注入；`v0.6.0` 对应 versionCode 600，沿用既有应用标识与签名。
