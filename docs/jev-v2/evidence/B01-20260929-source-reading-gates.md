# B01 来源与阅读阶段门闩：本地证据

2026-09-29。本变更沿用 D1 0046 已建的 `source` 和 `reading` 门闩行，不新增迁移。

- 来源领取在同一 D1 batch 内确定待执行阶段、更新来源租约并取得到期探测的唯一所有权。显式刷新或无原文属于来源；已存原文属于阅读。按 ID 领取和定时领取用同样的门闩条件；无合格任务时保留暂停回执及 Retry-After。旧客户端没有 `X-Cairn-Source-Component-Gate` 时只可领取关闭门闩的任务，不会占有到期探测。
- 来源/阅读付费准入和预算预留均检查本阶段门闩及探测租约。暂时性故障将门闩打开与当前任务失败一起提交，退避从 30 秒翻倍至最多 10 分钟，并尊重较长但有界的供应商提示。成功的来源 checkpoint 或阅读完成才在同一 batch 关闭本阶段探测，且必须匹配成功结算的付费尝试。
- 人工粘贴/遗留原文的 checkpoint 不证明抓取供应商恢复；若它占有来源探测，原子释放所有权并保留故障，下一条合格抓取可探测。
