## 变更

- **B01-T02/T03 权威目标与迁移**：新增 `worker/migrations/0010_authoritative_classification_target.sql`。
  `classification_targets`（不可变 spec/hash、requested model、policy、protocol、单调
  generation）与 `classification_target_state`（active 指针）。generation 0 预置 legacy
  目标，保证旧消费者兼容与**零历史回填**。0009 未修改（`git diff` 为空）。
  `classification_jobs` 增加 `target_generation`、`spec_id`、`input_revision`。
- **B01-T04 原子 claim 与能力握手**：`worker/src/classification.ts`。
  `GET/POST /api/enrichment/classifications/target` 返回当前目标并按消费者声明的
  capabilities 判断 `supported`；管理侧 POST 每次产生**新 generation**（回滚也是新
  generation 指向旧 spec，不倒退），支持 `expected_generation` 乐观并发检查。
  claim 只领取旧 generation 待迁移的任务或当前 generation 的 pending/failed/过期任务；
  已完成的当前目标任务不会被任意 policy 声明重新武装（消除版本竞争循环）。
  能力不匹配返回 409 `capability_mismatch`，不消耗 attempt。
- **B01-T05 局部失效守卫**：complete/fail 在写入前校验 active target、job 绑定的
  generation/spec、`input_revision`、lease 与有效期。旧 generation/旧输入/过期 lease
  分别返回 `target_changed`/`input_changed`/`lease_expired`，不覆盖当前投影。
- **B01-T06 retry 语义**：`retry` 只把任务重新武装到**当前**目标，不改服务器目标、
  不抢占活跃 lease。
- **B01-T07 note/URL 解耦**：`worker/src/index.ts` `updateLink` 拆分 `urlChanged` 与
  `noteChanged`。URL 变化才清除来源/译文/图片（保留人工 `why`/`curation`/`curation_status`）；
  note-only 保留快照、原文、译文、图片且不触发重抓，仅按旧语义失效分类 job。
- **B01-T08 完成幂等与查询**：`classification_operations` 记录 `operation_key` +
  payload hash。相同 key + 相同 payload 幂等返回既有响应（响应丢失后无需重放模型），
  不同 payload 返回 `operation_conflict`。legacy 消费者不传 key 时保持原 lease 语义。
- **B01-T09 typed 错误与 HTTP 映射**：`ClassificationErrorCode` → 明确 HTTP 状态
  （capability/target/input/lease/already-completed/operation-conflict = 409；config
  = 500；invalid = 400）。不再把所有情况压成通用 `lease_conflict`（保留其作为 legacy
  形状）。
- **B01-T10 文档**：README 新增“分类目标握手（v2，可选）”章节。

失败→通过记录：

- **B01-T01 版本竞争失败回归**：修改前，A 用 policy-a 完成、B 用 policy-b claim 会
  重新武装同一 job（`attempts` 增长、status 回到 pending），20 轮交替会重复领取。
  新增测试 `does not re-claim a completed target across A/B policy alternation (20 rounds)`
  断言 20 轮 claim 全部 204、最终 `status=completed`、`attempts=1`、来源快照不变。
  修改前该断言失败；修改后通过。
- **目标切换不覆盖投影**：`guards completion against a target switch (no stale overwrite)`
  在切换目标后用旧 lease complete，断言 409 `target_changed` 且 `links.classification`
  保持 NULL。
- **幂等**：`commits a lost completion idempotently by operation key without a second run`
  同一 operation_key 重放返回相同响应且不双写；不同 payload 409 `operation_conflict`。
- **并发 lease**：`keeps the target read and claim guard atomic under concurrent claims`
  并发两次 claim 只有一个 200，DB 中只有一条匹配 lease。
- **note/URL 解耦**：`index.test.ts` 新增 `invalidates stored source on URL change but
  preserves human curation`；原“content edits reset enrichment”测试改为断言 note-only
  保留 `original_text`/`summary`/`enriched_at`，且 URL 变化清除来源但保留 `why`。
