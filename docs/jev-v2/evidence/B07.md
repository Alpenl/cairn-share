## 变更

- **B07-T01 DTO 兼容**：`network/LinkEnrichment.kt`。`BookmarkClassification` 新增
  `contentFunctions`/`carriers`/`affordances`/`multiDimensional`；`decodeEnrichment` 解析 v2
  多选字段。v1 载荷不含这些键时 `multiDimensional=false`，**不把旧载荷冒充 v2**。
  `TaxonomyTerm` 增加 `deprecated`/`description`；`decodeTaxonomy` 用 `optJSONArray` 容忍缺失
  维度并解析 content_functions/carriers/affordances；缺失维度不被当作错误。
  新增 `FieldStatus` 枚举区分 accepted/rejected/abstained/not_run/not_applicable/stale。
- **B07-T02/T06 能力协商与安全边界**：`network/V2CurationClient.kt`。通过同源 Go 代理访问
  v2 端点；`V2Result.Unsupported` 明确表示后端不支持，调用方降级而非伪造字段。App 从不持有
  内部管理凭据。
- **B07-T04 字段级动作**：`FieldOverride` 携带 `field`/`term`/`action`/`operation_key`/
  `expected_revision`，`encode()` 生成请求体；`set_empty` 与 `reset` 编码不同。
- **B07-T05 离线动作队列**：`QueuedCurationAction` 只存**动作**（含 operation key 与
  expected revision），不存完整旧对象；`pendingActionsFor` 按账号过滤，切换账号/服务器不会误发。
- **B07-T03/T07 多维与实体状态**：`LinkEnrichment` 新增 `entityState`（默认 `not_run`，
  与 `completed_empty` 区分）；`BookmarkFilters` 新增 content_functions/carriers/affordances/
  entity_state，同维 OR、跨维 AND，与 B05 合同一致。
- **B07-T09 兼容**：v1 载荷可读且不标记多维；空 use 合法；第四 topic 完整解码（折叠是显示层）。
- **B07-T10 门禁**：Android unit/lint/build/androidTest 编译全部执行。
