# Cairn 浏览器收藏插件

0.2.0 新增直接采集当前页正文及图片、保留标题与列表结构，并固定显示保存反馈。
“已保存在本机”代表等待同步，“已同步”才代表服务器已接收。可以关闭弹窗，后台继续上传。
同步失败会保留完整图文，可在待上传列表重试。保存完成后按钮会锁定，编辑备注可发起新的收藏。

默认采集当前页已加载内容；取消勾选可仅存链接。首次可点击“允许读取跨站图片”，
以归档页面引用的 CDN 图片。权限未开启或图片无法获取时保留来源链接并提示缺失数量。
不会为了图片向目标站点发送 Cairn 令牌或登录 Cookie。

采集上限：正文约 90 KB、24 张图片、单图约 1 MB、总图片约 4 MB。
跨站取图最多约 12 秒；本机待上传图文总量约 24 MB。未加载、折叠、嵌入 iframe 中的内容不保证采集。

新图文接口依赖 Worker 数据库迁移 0053 及配套服务更新。旧服务返回不支持时会保留本机队列，
不会悄悄降级成仅存链接。请先升级服务，再安装或重新加载本版本插件。

Chrome：解压 `dist/cairn-chrome-0.2.0.zip` 到固定目录，在扩展页开启开发者模式，加载已解压扩展。
更新现有安装时替换同一目录中的文件，然后在扩展页点击重新加载，已有令牌与待上传队列保留。
Firefox：`dist/cairn-firefox-0.2.0.zip` 可用于临时调试安装；长期安装需要浏览器认可的签名。

开发：`npm ci`、`npm run verify`；Firefox 原生验证：`npm run test:firefox`。
产物：`npm run build`。测试使用本地模拟服务器，不访问生产收藏库或调用真实模型。

权限和数据处理见 [PRIVACY.md](PRIVACY.md)。
