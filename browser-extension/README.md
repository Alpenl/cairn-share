# Cairn 浏览器收藏插件

0.4.0 新增采集时选择合集；同时支持直接采集当前页正文及图片、保留标题与列表结构，并固定显示保存反馈。
“已保存在本机”代表等待同步，“已同步”才代表服务器已接收。可以关闭弹窗，后台继续上传。
同步失败会保留完整图文，可在待上传列表重试。保存完成后按钮会锁定，编辑备注可发起新的收藏。

默认采集当前页已加载内容；取消勾选可仅存链接。保存时会申请当前文章引用的媒体站点权限，也可点击“允许读取媒体站点”，
以归档页面引用的 CDN 图片。权限未开启或图片无法获取时保留来源链接并提示缺失数量。
不会为了图片向目标站点发送 Cairn 令牌或登录 Cookie。

采集上限：正文约 90 KB、24 张图片、单图约 1 MB、总图片约 4 MB。
跨站取图最多约 22 秒；本机待上传图文总量约 24 MB。未加载、折叠、嵌入 iframe 中的内容不保证采集。

新图文接口依赖 Worker 数据库迁移 0054 及配套服务更新。旧服务返回不支持时会保留本机队列，
不会悄悄降级成仅存链接。请先升级服务，再安装或重新加载本版本插件。

Chrome：解压 `dist/cairn-chrome-0.4.0.zip` 到固定目录，在扩展页开启开发者模式，加载已解压扩展。
更新现有安装时替换同一目录中的文件，然后在扩展页点击重新加载，已有令牌与待上传队列保留。
Firefox：`dist/cairn-firefox-0.4.0.zip` 可用于临时调试安装；长期安装需要浏览器认可的签名。

开发：`npm ci`、`npm run verify`；Firefox 原生验证：`npm run test:firefox`。
产物：`npm run build`。测试使用本地模拟服务器，不访问生产收藏库或调用真实模型。

权限和数据处理见 [PRIVACY.md](PRIVACY.md)。

## 同文补采、视频与音频

再次采集同一篇文章会更新最早的收藏，保留编号、时间及人工整理。微信公众号临时参数、X/twitter 的同文地址与通用跟踪参数不会制造新收藏；其他查询参数和路由片段保留区分。保存成功后可点“重新采集”。原收藏已有图片而这次采集不完整时，保留原内容并提示重试。

视频/音频实际下载后以 8 MB 分块归档，单文件上限 256 MB、每篇最多 16 项。X 通过选中帖子对应的公开媒体描述取得最高码率 MP4。普通文件可在阅读网页播放或下载。HLS 点播会连同音轨、播放列表、初始化片段和实际分片保存为 ZIP，下载后可在支持本地 HLS 的播放器播放；加密、直播、无法识别的 blob 播放器会明确提示尚未完成，不把外链视作已归档。

待上传媒体临时保存在本机 IndexedDB；关闭弹窗或后台重启后从服务器确认的分片继续，成功或移除队列后清理。完整文件下载前中断可能需要重新下载；未完成的分块上传会在过期前重建会话。超出大小、权限或来源限制时显示失败原因，正文保存与媒体归档的进度分别显示。


### 0.3.1 正文解析

正文提取复用 Defuddle 0.19.4，Markdown 转换复用 Turndown 7.2.4（GFM），DOMPurify 3.4.16 过滤可执行内容。所有依赖随安装包发布，仅在用户触发保存/预览后注入；关闭 Defuddle 的异步外部提取，不发送页面给 LLM 或第三方解析服务。X 仅处理当前帖，引用链接单列保存，保留多段正文。图片和媒体仍通过既有有界归档/续传流程保存。

## 采集时选择合集

弹窗直接显示使用中的合集，支持多选或不选。合集由你在网页/APP创建和管理，插件只选择归属。选择会随本机草稿和上传队列保存；正文保存后再加入合集，归属失败保留操作并可重试，避免重复采集。换账号时清空旧合集选择。版本冲突需点击重试确认按最新版本加入。

合集需配套0057/0058服务，插件通过能力确认防止旧服务忽略归属操作。自动整理在网页/APP由用户主动发起，默认审核；插件不会主动调用模型或改变合集定义。
