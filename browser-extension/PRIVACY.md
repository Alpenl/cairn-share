# Cairn 浏览器扩展的隐私说明

仅在你点击保存、右键收藏或主动启动批量补采时，扩展读取当前网页已加载的正文、标题、语言、链接和图片。
会跳过网页表单、脚本、导航及隐藏元素；不读取浏览历史或 Cookie。采集不是整站备份，
未展开、未加载、受浏览器保护或超出限额的内容可能无法保存，界面会提示截断或图片缺失。
取消“同时保存正文和图片”或收藏另一个链接时，仅保存链接和备注。

正文、取得的图片字节、链接、备注及随机 UUID 发送到固定收藏服务
`https://share.alpenl.com/api/captures/v2`；图片随后以独立二进制请求归档，仅链接收藏使用 `/api/links`。
访问令牌只通过该服务的 Authorization 头发送，图片站点不会收到令牌。
跨站图片的额外访问权限由用户主动开启；图片请求省略凭据、优先使用浏览器缓存。
服务端无需再次抓取已采集内容。浏览器自身可能为取得缺失图片发起网络请求。

令牌、设置、草稿、正文和任务描述存入当前浏览器的 `storage.local`；页面图片快照及取得的媒体文件存入本机 IndexedDB，不使用 `storage.sync`。待上传内容总量有限；上传成功后移除本机队列内容，保留最近操作的状态。
`unlimitedStorage` 用于持久保存待上传图文，避免浏览器常规配额造成丢失。
卸载会清除这些本机数据，不会删除服务端收藏。移除待上传记录会丢弃尚未同步的内容。

开启正文整理后，已存正文可由服务端发送给单独配置的整理模型；原内容始终保留。
插件不接收或保存 `CAIRN_ENRICHER_TOKEN`，使用与 Android 相同的 `CAIRN_API_TOKEN`。
无广告、分析上报或后台网页监控。


视频和音频只在主动采集后获取；X 使用公开帖子媒体描述，绑定当前帖子的编号。请求不附带用户 Cookie 或 Cairn 令牌。源文件暂存于本机 IndexedDB 并分块发送到同一收藏服务的 `/api/media/uploads/`，成功或从队列移除后清理。HLS 包包含实际点播分片，不绕过加密或访问控制。插件准备保存界面时会读取当前页的媒体地址以确定应申请的具体站点权限，不上传正文。

正文解析库在浏览器本地运行，随插件打包；未接入云端解析或 LLM。解析仅发生于用户请求的当前页保存/预览或批量任务，第三方异步解析关闭。

合集列表、选择和待提交归属保存在本机，按当前访问凭据隔离；合集请求只发给固定收藏服务的 `/api/collections`。插件不会自动创建或改名合集。用户在网页/APP主动发起自动整理时，服务端可把已有收藏正文、备注以及所选合集名称/说明交给 Jev 判断；默认生成预选等待审核，直接应用需要用户明确选择。

批量补采从固定收藏服务分页读取缺少正文的收藏。首次启动需允许网站访问权限；扩展逐篇在后台标签页打开链接，网页本身使用浏览器现有登录会话，扩展不直接读取 Cookie。页面因此会收到正常浏览请求。采集完成会关闭扩展创建的后台标签页；用户切换到该页会暂停并保留页面。任务列表和进度留在本机，重新扫描时替换；重启浏览器后默认暂停，需主动继续。关闭面板不会停止采集，可随时点击暂停。
