连接与偏好

浏览器与 Android 使用同一份收藏库。填写 Android 设置中使用的访问令牌即可连接。

收藏会提交到这里，随后由服务处理 X 增强内容。

令牌仅保存在当前浏览器，不参与浏览器账号同步。

待上传 0

关闭弹窗后仍会上传。连接中断时保存在本机，浏览器运行期间自动重试。

如何收藏

点击工具栏图标，填写可选备注并保存；也可以右键收藏页面或链接。快捷键 Alt + Shift + C 打开收藏面板。

扩展只发送你主动收藏的链接、备注和重试标识。页面标题用于本机展示；不读取网页正文、表单、Cookie 或浏览历史。卸载扩展会清除本机草稿和待上传收藏。
